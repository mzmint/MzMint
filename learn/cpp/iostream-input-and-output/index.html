iostream, Input, and Output

The iostream library is the most used library in C++.

It comes with the Standard Library and its main purpose is to receive input and send output through the console.

To start using the library, add #include <iostream> at the top of the .cpp file.

Output

Output is the one of the most useful features in programming, as it lets you print anything in the console, like words, values, or texts.

The object most used for output in the iostream library is std::cout.

You can use std::cout to print a sentence or word, like std::cout << "Hello, World!";, you can print values: std::cout << 55;, you can print variables: std::cout << variable;, and much more.

Concatenating

To concatenate values with std::cout you just need to add << between them, for example: std::cout << "Hello, " << "World! " << 16; which would print Hello, World! 16.

New Line

To switch to a new line using std::cout you just need to put std::endl where you want to, for example: std::cout << "Hello" << std::endl << "World";, which would print

Hello
  World

You can also use the control character \n where you want to switch to a new line, like std::cout << "Hello\nWorld";

Input

Input is used to receive user input from the console and store it in a variable;

The object most used for input in the iostream library is std::cin.

You can store a string in a variable (numbers work too and it only stores up to a whitespace, so if the input is John Smith it only stores John, later we will learn how to store a full string) using std::cin >> variable;

Multiple Inputs

You can take multiple inputs at once using std::cin by adding >> between the variables, like std::cin >> name >> value;

Code example

Heres a code example combining everything we've learned:

#include <iostream>

  int main() {
      int number;

      std::cout << "Enter a number: ";
      std::cin >> number;

      std::cout << "You entered: " << number << std::endl;

    return 0;
  }
