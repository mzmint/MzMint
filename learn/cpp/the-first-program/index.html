The First Program

The simplest program that you can have in C++ is this:

int main() {
    return 0;
  }

The Main Function

The main function is defined asmain() {} and it usually doesn't have any parameters.

When you run a C++ program, the code insidemain is the first part of the code that executes, no matter where it is.

Theint before main indicates that the function returns an integer.

Exit Code

At the end of the code inside main we putreturn 0; to indicate that the program ran successfully giving an exit code of 0.

Exit code 0 means that the program ran successfully and exit code 1 usually means theres an error, but you can still havereturn 1; in your code.

Exit codes are an integer from 0 to 255, but these are the most common.
