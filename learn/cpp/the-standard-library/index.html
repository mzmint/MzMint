The Standard Library

The standard library is a collection of libraries that comes with most compilers, usually as libstdc++, and has some of the most used libraries in C++.

How To Use It

To use the standard library, you just need to add #include <library_name> at the top of the file.

The library uses the namespace std::, which indicates that the function, class or object comes from the standard library, for example: std::cout << "Hello, World!"

You can have using namespace std; at the top and only do cout << "Hello, World!" but later it will be better to not use it.

Some of the most used libraries are: iostream, fstream, cmath, random, string, vector, etc.
