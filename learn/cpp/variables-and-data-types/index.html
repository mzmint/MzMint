Variables and Data Types

Variables

Variables are some of the most useful things is programming.

They can be used to store constant values (later we will learn how), do calculations, and much more.

To make a variable in C++, put the variable type, the name, an =, and the value, for example: int number = 55;

You don't need to immediately assign a value to a variable, for example: int number;

To change the value of a variable after it has been created, you don't need to put the type, just the name and the value, for example: 

int number = 55;
  number = 16;

which makes number equal to 16;

Data Types

Data types are used in variables, to decide if the variable is a number, a word, etc., in functions, do decide what the function returns, etc.

There are dozens of data types, but these are the most used;

int

int stands for integer, and it's the most used data type in coding.

It can hold any 32 bit value, which means it can be any integer from -2147483648 to 2147483647.

double

double is a data type that can hold numbers with decimal points.

It holds a 64 bit value with a range from −1.7976931348623157×10^308 to 1.7976931348623157×10^308.

A double doesn't need to be exactly 64 bits, but we will see this later.

bool

bool is one of the simplest data types. it holds either true or false

string

string is a special data type. to use it you need to add #include <string> at the top of the file

to make a string variable you do std::string message = "Hello, World!";

The limit of a string is 2^62 characters, or 4611686018427387897 characters, but you can assume its infinite because you would need millions of terabytes to store a string that big.

There are other data types, which you will learn later, but these are the most used.

Here's an example of variables of the four types we've learned:

int age = 16;
  double height = 1.75;
  bool isProgrammer = true;
  std::string name = "Alex";
